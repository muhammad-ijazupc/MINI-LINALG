# Concurrent Linear Algebra Engine & CI

**GitHub Repository:** https://github.com/muhammad-ijazupc/MINI-LINALG

## Project Overview
This project implements a Python linear algebra library called `mini_linalg`, including Vector and Matrix classes.

## Features
- Vector addition and subtraction
- Scalar multiplication and dot product
- Matrix multiplication
- NumPy-based vector operations
- Batched vector addition
- Automated testing with pytest
- Code style checking with flake8
- Git feature branches and GitHub Actions CI

## Testing
All 12 tests passed locally. The flake8 check reported no errors, and the latest GitHub Actions workflow completed successfully.
